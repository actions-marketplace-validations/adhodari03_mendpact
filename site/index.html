YOUR FIRST CHECK

Start with one endpoint.

Python 3.12+ for the CLI. A reviewed endpoint and a few commands to get your first report.

Clone. Install. Inspect.

Install from the repository, then scan a server you maintain. Replace the example URL with your own HTTPS MCP endpoint.

Ready for CI? The initializer creates a scan workflow and a production policy in your application repository.

GitHub Action guide ↗Security boundaries ↗
terminal 
git clone https://github.com/adhodari03/mendpact.git
cd mendpact
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
mendpact scan https://your-server.example/mcp \
  --output report.json
HTTPS required by default • Report saved locally
